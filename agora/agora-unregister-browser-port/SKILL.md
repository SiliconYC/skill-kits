# 注销已有浏览器测试端口

仅处理 [Agora 端口登记](https://github.com/SiliconYC/agora/blob/dev/registry/ports.md) 中用于**本地浏览器网页审查／调试**的端口预留。

## 何时触发

- 仓库退役，或项目不再提供本地网页测试入口。
- 项目永久更换端口，旧的端口段确定不再使用。

**不触发**：开发服务器暂时关闭、Agent 任务结束、页面暂时不可访问、Python 等进程间通信服务变动。

## 执行

1. 读取 Agora `dev` 最新 `registry/ports.md`，核对目标仓库及其固定、备用端口，检查是否仍有工作树或维护中的浏览器测试入口依赖它们。
2. 确认不再需要后，从登记表移除该仓库的端口预留；不得删改其他仓库的分配。若只释放部分端口，则只调整相关范围。
3. 同步修改原项目的 `AGENTS.md`、启动配置或文档中已失效的端口约定，避免复活旧分配；项目整体退役时不必做无意义的代码改造。
4. 并发变更时先重新核对最新表格，避免覆盖新登记；核验更改并返回 Agora 文档链接。若未完成同步，明确报告剩余项。

注销登记不意味着应终止任何运行中的进程，尤其不得结束身份不明的服务。
