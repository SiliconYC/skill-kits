# 跨仓库知识协作 Skill 触发补丁

本文件供并入现有项目或 Agent 软件的 `AGENTS.md`，不要整体覆盖原文件。

- 日常开发、调试或研究中，主动留意有长期价值、值得其他仓库复用的经验与教训；先判断价值和适用范围，再查重。
- 有价值但尚待核实、需要讨论或跨仓库协调的主题：`agora-create-discussion`。
- 已核实、稳定、适用于多个仓库的做法、教训或决策：`agora-create-wiki`。
- 新项目需要长期预留本地浏览器预览／调试端口：`agora-register-browser-port`。
- 项目退役或永久取消本地网页测试入口：`agora-unregister-browser-port`。

不记录短期、琐碎或仅与单仓库相关的内容；已有条目优先补充而非重复创建。人类可主动要求记录，但这不是主要触发方式。
端口两项不用于普通程序间通信、内部服务或临时停机。
