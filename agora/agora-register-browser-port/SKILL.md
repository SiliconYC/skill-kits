# 为新项目分配浏览器测试端口

仅适用于供人类或 Agent **通过本地浏览器访问**的网页预览、交互检查、前端调试服务。

**不触发**：Python 程序间通信、普通 HTTP API、数据库、微服务内部端口、远程部署、仅启动已有端口的服务或临时停机。

## 执行

1. **先读** [Agora 端口登记](https://github.com/SiliconYC/agora/blob/dev/registry/ports.md) 的最新 `dev` 版本，并核对新项目现有 `AGENTS.md`、开发服务器配置和脚本。
2. 对照已预留的固定及备用范围，选择不重叠的端口；尽量沿用登记表的连续端口段惯例，但不强占已登记端口。核对同一主机的实际占用，登记只表示预留，并非运行时锁。
3. 在新项目开发配置与根目录 `AGENTS.md` 写明固定端口、备用范围、启动方式、常用 URL 和占用处理原则；明确不杀死身份不明的进程、不擅用别的项目端口。
4. **尽快同步**更新 Agora `registry/ports.md`，记录仓库、固定端口、备用端口和浏览器入口。发生并发写入冲突时，重新读取最新登记后核对、重试，不能覆盖他人的新增记录。
5. 核验两仓库记录一致；如果 Agora 写入失败，明确标注“尚未登记”，不得宣称端口已完成全局预留。

项目更换端口时，应同步移除旧登记，避免永久占位。
