# 构建与发布 Skill 触发规则

> [!note]
> 本文件供并入已有项目或 Agent 软件的 `AGENTS.md`，不得整体覆盖原有规则。本目录与 `tenet/`、`agora/` 平级。

## 定位

`builder/` 收录跨项目复用的构建、编译、打包、发布与构建产物验收技能。只沉淀可执行的方法、边界及验证标准；不将单一项目的依赖排除清单视作通用答案。

## 必须加载的 Skill

- 使用 PyInstaller 构建 Python 可执行文件或 macOS `.app`，尤其遇到安装包过大、无关依赖被收集、动态库或 Qt 插件膨胀时，必须先加载 `builder-pyinstaller-size-optimization`。
- 执行构建体积专项优化前，同样应加载该 Skill，并遵守其中的依赖溯源、环境隔离、运行验收和构建产物清理规则。

## 通用约束

- **不得为了缩包而擅自卸载、升级或修改正在使用的 Python 环境中的第三方库。** 如确需隔离环境，应另行创建独立环境，并在用户授权的范围内操作。
- 不以文件名猜测依赖是否无用；先查证收集原因，再调整 `.spec` 或 Hook，并以真实启动与功能测试验证。
- 不擅自修改共享生产组件，不为缩包删除既有功能，不以测试通过冒充真实 GUI 或设备联调。
- 对旧版应用及中间产物的删除，遵循用户明确指定的保留策略和路径边界；只清理确认属于本任务的产物。
- 达到合理体积且功能验收通过时，及时收口，不将无限缩包作为默认目标。
