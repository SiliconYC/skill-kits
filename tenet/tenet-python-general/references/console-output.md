# Python 控制台输出格式

当 Python 代码需要输出控制台状态信息时，统一使用中括号标签开头，以便人类和 Agent 快速识别信息性质。

## 合法标签

只使用以下八个两字标签：

- `[信息]`
- `[提示]`
- `[警告]`
- `[错误]`
- `[开始]`
- `[结束]`
- `[完成]`
- `[中断]`

不要自行发明 `[日志]`、`[底盘]`、`[启动器]`、`[连接]` 等新的标签。

## 写法

标签之后直接写具体、可定位的信息。需要指出对象或动作时，优先包含真实 class、def、任务对象或关键值，而不是输出模糊的“发生错误”。

示例：

- `[开始] 开始扫描插件清单。`
- `[提示] class 测试_类 -> def 测试_方法 收到不合法参数类型。`
- `[警告] 无法完成缓存刷新，准备终止本次操作。`
- `[完成] 已写入 12 个结果。`

## 渐进治理

历史代码可能存在不符合当前枚举的标签。不要为了统一格式单独扩大任务范围；但当当前任务已经修改某个文件中的相关输出时，应顺手把直接涉及的旧标签改为合法值。
