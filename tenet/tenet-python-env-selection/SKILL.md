# Python 环境选择规范

无论是在测试还是在生产环境下执行 Python 代码，必须按以下优先级选择环境：

1. **用户指定**：若用户明确指定了环境，绝对优先使用。
2. **默认环境 `vt`**：若用户未指定，优先使用名为 `vt` 的 Anaconda 环境，自行判断其是否存在且满足要求。
3. **备选环境**：若 `vt` 无法满足要求，按顺序依次检查 `vee_lab` 和 `vt_torch` 是否存在并满足要求。
4. **停机报错**：若上述环境均不符合要求，立即停止执行并通知用户。

### 红线要求

- 任何情况下，**严禁修改现有环境**（如执行 pip/conda install）。
- 任何情况下，**严禁自行创建新环境**。
