# GitHub 新仓库初始化

由于 Agent 通常没有创建或删除 GitHub 仓库的权限，仓库初始化只能在用户已创建好的现有仓库基础上进行修改。

在我们的开发习惯中，`main` 分支属于受保护的冷分支，绝大多数日常开发都在 `dev` 分支及其派生分支中进行。因此，新仓库初始化的核心目标是建立 `dev` 分支，并将其设置为 GitHub 仓库的默认分支，而不是沿用 GitHub 默认的 `main` 分支。

## 前置条件：确认属于新仓库

执行任何初始化操作前，必须先检查仓库当前的文件内容与目录结构，确认其确实是一个全新的仓库：

- **新仓库特征**：仓库内通常只有 `README` 文档（如 `README.md`），有时还会包含 `.gitignore` 文件，除此之外没有其他实质性的项目内容。
- **非新仓库中断点**：如果发现仓库内明显存在大量代码或已成型的业务目录，说明这不是一个新仓库。此时**严禁执行本初始化流程**，应立即停止并告知用户。

## 初始化执行步骤

确认目标仓库属于新仓库后，严格按以下顺序执行初始化：

### 第一步：检查 `main` 分支是否存在

检查本地及远端仓库是否存在 `main` 分支（正常情况下，新建的 GitHub 仓库必然存在 `main` 分支）：

- 若 `main` 分支存在，确保工作区处于最新的 `main` 分支，继续执行下一步。
- **异常中断点**：若发现 `main` 分支不存在，**立即停下来通知用户**，不得擅自创建 `main` 分支或继续执行后续步骤。

### 第二步：检查并升级 `.gitignore` 规则

检查仓库根目录下是否存在 `.gitignore` 文件：

- 若不存在，在根目录下新建 `.gitignore` 文件。
- 若已存在，检查现有规则并合并补齐缺失的忽略项，避免遗漏或重复。
- 无论新建还是追加，都必须确保包含以下标准屏蔽规则：

```gitignore
# 通用临时文件
**/__pycache__/
**/.DS_Store
.cache
*.tmp
*.temp
*.bak

# 日志
*.log

# React 包和产物
node_modules
.vite/
**/.vite/
.env
.env.*
!.env.example

# 本地测试缓存
**/.pytest_cache/
*.pyc
*.pyo
*.swp
*.swo

# AI Agents 遗留文件
.claude
.superpowers
docs/superpowers

```

- 完成 `.gitignore` 的新建或补齐后，将其提交（`git commit -m "chore: 初始化 .gitignore 屏蔽规则"`）并同步推送到远端 `main` 分支。

### 第三步：检查并创建 `dev` 分支

检查本地及远端仓库是否存在 `dev` 分支：

- 在全新的 GitHub 仓库中，通常不存在 `dev` 分支。此时需基于 `main` 分支为用户创建 `dev` 分支（`git switch -c dev`），并将其推送到 GitHub 远端建立追踪关系（`git push -u origin dev`）。
- 若 `dev` 分支已经存在，则切换到 `dev` 分支并确保本地与远端同步，无需重复创建。

> [!note] 请确保 `dev` 分支拥有上述 `.gitignore` 文件。

### 第四步：尝试将 `dev` 设为默认分支

尝试将 GitHub 仓库的默认分支从 `main` 切换为最常用的 `dev` 分支：

- 优先使用当前环境中可用的工具（例如执行 `gh repo edit --default-branch dev` 或调用对应的 GitHub API 工具）直接将远端仓库的默认分支修改为 `dev`。
- 若因权限受限或当前环境未配置对应工具而无法自动完成修改，需在完成前两步后明确告知用户，请用户在 GitHub 仓库设置中手动将默认分支切换为 `dev`。

## 关键检查点对照表

| 检查项 | 正常预期状态 | 实际状态与处理动作 |
| --- | --- | --- |
| **仓库文件结构** | 仅有 `README`（有时含 `.gitignore`） | 若已存在大量代码，判定为非新仓库，**立即停止，不执行初始化** |
| **`main` 分支** | 必然存在 | 若不存在，**立即停下来通知用户** |
| **`dev` 分支** | 新仓库中通常不存在 | 基于 `main` 创建 `dev` 分支并推送到 GitHub 远端 |
| **远端默认分支** | 初始通常为 `main` | 尝试将 `dev` 设为默认分支；若权限或工具受限则提示用户手动设置 |
