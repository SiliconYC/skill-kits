## 必须加载的 Skill

以下为 `agora` 系列 Skill:

- Git 分支切换、提交、合并或推送：`tenet-git-branch-workflow`。
- 创建或修改 Agent Skill：`tenet-chinese-skill-creator`、`tenet-markdown-format`。
- 创建、修改或审查 Python 代码：`tenet-python-general`、`tenet-ai-oriented-comments`。
- 编写、重构或审查代码注释：`tenet-ai-oriented-comments`。
- 创建、修改或审查 Markdown：`tenet-markdown-format`。
- 初始化新建 GitHub 仓库：`tenet-github-repo-init`。
- “GitHub 摸底研究”或系统性开源仓库研究：`tenet-github-repo-research`。
